Cómo funciona

  1. Pegas la URL de la playlist de YouTube Music.
  2. La app lee la playlist con yt-dlp (solo metadatos) y te muestra las pistas.
  3. Seleccionas calidad y canciones, y eliges la carpeta de destino.
  4. yt-dlp descarga el mejor audio y ffmpeg lo convierte a MP3 con portada y metadatos.
  5. Listo: tus archivos quedan numerados y ordenados en tu PC.

Instalación (Windows)

Requiere Python 3.11+ y conexión a Internet. Eso es todo.

# 1) Clona el repositorio
git clone https://github.com/SandovalJon/ytmp3.git
cd ytmp3

# 2) Crea el entorno virtual e instala dependencias
python -m venv .venv
.venv\Scripts\python.exe -m pip install yt-dlp flask imageio-ffmpeg

# 3) (Opcional, recomendado) Deno para algunos formatos de YouTube
winget install --id DenoLand.Deno -e --scope user

# 4) Arranca la app y abre el navegador
.venv\Scripts\python.exe app.py

O simplemente haz doble clic en Iniciar.cmd. La app se abre en http://127.0.0.1:5088.

Si algo falla

La página 127.0.0.1:5088 no abre o el puerto está ocupado

Cierra otra copia de la app y reintenta. O arranca en otro puerto: set PORT=5099 & .venv\Scripts\python.exe app.py y abre http://127.0.0.1:5099.

“Deno no encontrado” o error de formato de YouTube

Instala Deno con winget install --id DenoLand.Deno -e --scope user, cierra y reabre la terminal, y vuelve a arrancar con .venv\Scripts\python.exe app.py.

“Inicia sesión para confirmar que no eres un bot”

Es una protección anti-bots. Exporta tus cookies con “Get cookies.txt LOCALLY” y súbelo en la app, en el campo de cookies. Es solo local y se borra al terminar.

Una canción falla y las demás siguen

Es normal: el error queda en el registro del trabajo. Usa el botón “Reintentar errores” cuando termine. Si falla todo, actualiza yt-dlp: .venv\Scripts\python.exe -m pip install -U yt-dlp.

Preguntas frecuentes

¿Por qué no descarga directo desde esta página web?

GitHub Pages solo entrega archivos estáticos; no puede ejecutar el motor de descarga. La conversión ocurre siempre en tu PC, que es lo que hace que funcione y que sea privada.

¿Funciona con playlists privadas?

Sí. Exporta tus cookies con una extensión tipo “Get cookies.txt LOCALLY” y súbelo en la sección “Playlist privada” de la app. Las cookies nunca salen de tu equipo.

¿Qué hago si YouTube pide “inicia sesión para confirmar que no eres un bot”?

Es una protección anti-bots. Sube tu archivo de cookies en la app (como arriba) y reintenta. Conéctate una vez desde tu navegador e inténtalo de nuevo.

¿Puedo descargar videos eliminados o privados?

No. Aparecen atenuados con su casilla deshabilitada; no se pueden ni tiene sentido intentarlo.
